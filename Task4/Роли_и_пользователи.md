| Роль           | Права роли                                                          | Группы пользователей         |
|----------------|---------------------------------------------------------------------|------------------------------|
| secret-manager | secrets: `get`, `list`, `watch`, `create`, `update`, `delete`       | security-engineers           |
| secret-reader  | secrets: `get`, `list`, `watch`                                     | devops-engineers             |
| pods-manager   | pods: `get`, `list`, `watch`, `create`, `update`, `patch`, `delete` | devops-engineers, developers |
| pods-reader    | pods: `get`, `list`, `watch`                                        | operations-engineers         |
- Для примера привёл роли и права для управления только секретами и подами в Kubernetes. Можно было бы выделить так же
роли для управления logs, configmaps, deployments и т.д.
- Security engineer на всю компанию один, в этом примере я выделил 
для него группу с ролью secret-manager в порядке условности.
